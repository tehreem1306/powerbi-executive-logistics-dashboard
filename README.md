# Executive Logistics & Fleet Performance Dashboard (Power BI)

An end-to-end enterprise logistics analytics project built to transform complex operational data into actionable visual insights for stakeholders.

## 📊 Project Overview
This project focuses on analyzing logistics, transport operations, and maintenance logs using a **14-table star-schema** data model. The dashboard provides deep visibility into fleet efficiency, driver performance, safety tracking, and executive summaries.

## 🛠️ Tech Stack & Tools
* **Power BI:** Data modeling, DAX measures, interactive UI/UX design, and button navigation.
* **Data Modeling:** Relational 1-to-Many star-schema architecture.
* **Workflow:** Data cleaning & preparation, relationship modeling, custom metric creation, and visual storytelling.

## 📈 Key Features & Pages
1. **Executive Overview:** High-level KPIs including Total Trips, Average MPG, and overall fleet health.
2. **Fleet Operations:** Transport metrics, route distribution, and fuel/maintenance analysis.
3. **Driver Performance:** Tracking individual driver metrics and trip efficiency.
4. **Final Report & Insights:** Dedicated executive reporting page featuring structured key insights and strategic recommendations.
5. **Interactive Navigation:** Seamless page-switching via custom left-side menu buttons.

## 🚀 Key Metrics Tracked
* `Total Trips Completed`
* `Average MPG (Miles Per Gallon)`
* `170 Total Incidents` (categorized by incident types such as DOT violations, accidents, etc.)

## 📂 Project Structure
* Data cleaning and formatting protocols.
* Star-schema relational data model.
* Custom DAX measures and calculated columns.
* Multi-page interactive Power BI report (`.pbix`).
